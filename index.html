Perimeter of 1s — think it like an interview

Formula baad mein. Pehle observation, phir galti, phir fix.

PERIMETER =0

Interview mode — how I would solve this

  1. Ek 1 ek square hai → 4 sides.
  2. So every 1 initially contributes +4.
  3. Adjacent 1s ek side share karte hain.
  4. Shared side perimeter mein nahi honi chahiye.
  5. But +4 +4 karte waqt woh side 2 baar count hui.
  6. Therefore every shared side gives −2.
  7. Ab shared sides count karni hain.
  8. All four directions check karenge toh duplicate milega.
  9. Matrix left-to-right, top-to-bottom traverse ho raha hai.
  10. Left aur up already visited hain.
  11. So sirf left aur up check karna hai.
  12. Right/down miss nahi honge — jab woh cells current honge, tab ye left/up ban chuke honge.

The code

for (int i = 0; i < n; i++)
  for (int j = 0; j < m; j++)
    if (mat[i][j] == 1) {
      ans += 4;                                  // naya square, 4 sides
      if (i > 0 && mat[i-1][j] == 1) ans -= 2;   // UP mein 1 → shared side
      if (j > 0 && mat[i][j-1] == 1) ans -= 2;   // LEFT mein 1 → shared side
    }
  • i > 0: pehli row ke upar koi cell nahi hota, isliye mat[-1][j] padhna invalid hoga. Guard zaroori hai.
  • j > 0: pehle column ke left koi cell nahi hota — same reason.
  • mat[i-1][j] = ek row upar, same column → UP. mat[i][j-1] = same row, ek column peeche → LEFT.
  • −2 kyun: woh side pehle upar/left wale square ne +4 mein count ki thi, aur ab current ne bhi. Dono counts hatane hain.

Complexity

Time O(n × m): har cell ek baar visit hota hai aur har visit mein sirf 2 fixed checks (left, up) — koi DFS/BFS, koi repeated visit nahi.
Space O(1): sirf ek integer ans; matrix modify ya copy nahi karte, koi visited array nahi.

Doubts, cleared

Why +4?Har 1 ek square hai, aur square ke 4 sides hote hain.
Why −2?Ek common side dono squares ke +4 mein ek-ek baar count hui = 2 counts. Woh internal hai, dono hatao.
Why not check all four neighbours?Same shared side dono cells se discover hogi → duplicate. Humein har side ek hi baar chahiye.
Why only LEFT and UP?Left-to-right, top-to-bottom traversal mein yahi do neighbours already visited hote hain.
Won't we miss RIGHT? DOWN?Jab right cell current hoga, pichla cell uska LEFT hai. Jab bottom cell current hoga, pichla cell uska UP hai. Side tab detect hogi — exactly once.
Multiple separate figures?Har 1 independently +4; sirf real shared side −2. Figures connected hon ya nahi, farak nahi padta.
Do I need DFS/BFS?Nahi. Sirf local neighbour checks during normal traversal.

Final takeaway

Har 1 ko ek square samjho. Pehle uske 4 sides count karo. Jo side kisi neighbouring 1 ke saath share ho rahi hai, woh internal hai — aur woh 2 baar count hui thi. Bas uske 2 counts hata do.

+4 for every 1 · −2 for every shared side · Left + Up (kyunki baaki directions baad mein khud left/up ban jaati hain).
